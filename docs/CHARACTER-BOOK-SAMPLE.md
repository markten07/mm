# 모바일 캐릭터북 시안 v2

## 보기
http://localhost:8000/character-book-sample.html

이전 문서형 시안을 조사 결과에 맞춰 교체했다. 한소설을 대상으로 한 독립 검토 화면이며 1.html~4.html을 교체하거나 실제 방에 접속하지 않는다.

## 이번 변경
- 첫 화면: 현재 진행 단계, 지금 할 일, 주 실행 버튼 하나를 우선 배치.
- 종이색·명조·긴 세 컷 도입과 읽기 모드 탭 제거. 어두운 중립 배경·시스템 고딕·한 가지 강조색으로 통일.
- 한 질문씩 역할을 확인하는 10개 화면. 조사 제안의 6~8개는 초기 가설이었으며, 기존 배경·관계·행적·행동 기록·규칙을 빼지 않도록 10개로 나눔.
- 진행 위치와 일정한 하단 다음 버튼. 긴 내용은 정상 스크롤하며 본문을 작게 줄이지 않음.
- 내 역할·조사·단서함의 하단 탐색.
- 확인 완료 후 질문 형태의 빠른 찾기: 관계·행적·답변·비밀.
- 시간별 행적은 시각을 눌러 해당 내용만 확인. 원문 의미를 유지하며 완결된 문장으로 정리.
- 질문별 참고는 사실·발언 예·기억할 점으로 구분. 추측을 확정 사실로 안내하지 않음.
- 화면 덮기와 이전 내용 다시 보기.

## 현재 단계 시연
상단 ‘시안’ 버튼에서 역할 확인·자기소개·조사·회의·투표 단계의 첫 화면을 비교할 수 있다.
이 설정은 시안 내부의 단계 전환이며 실제 진행자/Firebase와 연결되지 않는다. 읽던 화면을 서버가 강제로 전환하는 기능은 없다.

## 조사 연습
조사 탭에서 연습용 파티 초대장 한 장을 뒤집고 자동 보관을 체험한다. 실제 단서가 아니며 조사 횟수에 영향을 주지 않음을 화면에 표시한다. 연습 카드의 내용은 이미 알려진 축하 모임 설정뿐이다.

## 원본과의 관계
- 2.html의 ME 원본과 시안 데이터가 동일함을 검사. 원본 인물 데이터 파일은 수정하지 않음.
- 각 원문 사실을 배경·행적·기록 화면과 빠른 참고에 분배.
- 원문에서 모순될 수 있는 행동 부인 문구를 답변 예시로 사용하지 않음.
- 다른 인물만 아는 비밀이나 정답 추론을 추가하지 않음.
- 현재 역할 데이터는 시안용 복사본. 실제 통합 시에는 같은 원본에서 브리핑·참고 화면을 생성하도록 재구성 필요.

- JS 구문·로컬 파일 존재·원본 인물 데이터 일치·게임 DB/저장소 접근 없음 검사 통과.

- 실사용자의 이해도·몰입도 개선은 아직 검증하지 않음. MOBILE-ROLEBOOK-MARKET-RESEARCH.md의 사용자 테스트를 다음 검토 기준으로 사용.

최종 화면 확인: 390×844 및 320×640에서 가로 넘침 없음·주 실행 버튼 표시 확인. 단계 시연의 회의 화면, 화면 덮기, 최신 행적 문장 표시 확인. 브라우저 오류 로그 없음.

## 행적의 이유와 지시 대상 보완
- 한소설 원문의 계약상 이혼·배상 위험, 아내의 과거 조사, 투자 실패, 유산·보험 조사에서 살해 계획과 살충제 구매·투입으로 이어지는 맥락을 안내.
- 19:30의 모호한 ‘확인’은 백비서 원문(3.html)의 ‘테이블 확인’으로 구체화. 확인할 물건이나 지시의 숨은 의도는 추가하지 않음.
- 역할 안내, 빠른 시간별 행적, 비밀 참고, 질문별 참고에 같은 맥락을 제공. 살해 시도와 실제 사망 원인을 구분.

## v3 · 읽기 부담 개선
- 기존 인물 초상을 활용한 관계 카드. 홍대표는 초상 원본이 없어 이름 표식 사용. 관계 한 줄은 항상 표시하고 원문 관계 설명은 펼치기 제공.
- 동기를 위협 → 금전 압박 → 살해 계획의 세 단계로 표현. 핵심 동기와 행동은 숨기지 않음.
- 19:30은 식당 → 주방과 두 행동으로 구분. 안내와 빠른 행적 참고에서 같은 장면 컴포넌트를 사용.
- 읽는 중 하단 메뉴를 숨기고 이전·다음 한 줄로 축소. 완료 후 기존 메뉴 복원. 네 개의 읽기 주제 중 현재 위치 표시.
- 페이지를 오갈 때 읽던 위치와 펼친 설명을 메모리 안에서 복원. 새로고침 시 초기화 정책 유지.
- 검증: JS 구문과 기존 게임 검사 2개 통과. 브라우저에서 관계 펼치기·복원, 10페이지 완료, 메뉴 복원, 시간별 행적을 확인. 320×640에서 가로 넘침 없음. 사용자 이해도 개선은 추가 사용성 검증 필요.
- 화면: screenshots/mobile-role-relations-v3.png, screenshots/mobile-role-scene-v3.png.

## 정체 확인 전 가림
- ‘나는 범인인가요?’와 비밀 다시 보기에서는 확인 버튼을 눌러야 정체 및 관련 내용이 표시된다. 숨긴 내용은 화면 DOM에도 렌더링하지 않는다.
- 주변 시선 확인 문구, 다시 가리기 버튼 제공. 이동·화면 덮기·탭 비활성화 시 다시 가림.
- 최초 정체 확인 전에는 다음 버튼 비활성화. 한번 확인한 뒤에는 반복 확인을 강제하지 않음.
- 브라우저에서 최초 가림, 확인 후 공개, 다음 버튼 활성화, 재방문 시 자동 가림 검증. 기존 자동 검사 통과.
