# 프롤로그·진상 영상 제작 구성안

## 제작 범위
영상 편집 전 검토용 구성안이다. 완성 영상은 아직 제작하지 않았다.
현재 웹의 이미지, 자막, 나레이션 재생과 조작을 그대로 제공한다.
공용 화면에서 전원 시청하며, 진상은 최종 투표가 끝난 뒤에만 연다.

## 프롤로그
- 기존 assets/prologue-narration.mp3 음성(README 기준 약 113초)을 기준으로 편집한다. 실제 파일 길이는 편집 시 확인한다.
- index.html의 PROLOGUE 데이터에 있는 장면·대사·이미지를 원본 대본으로 삼는다.
- 도입: 저택과 모임의 분위기 → 사건 발생 → 네 용의자 소개 → 조사 시작.
- 마지막 화면: “각자 휴대폰에서 캐릭터북을 열어주세요.”
- 등장인물의 범행 비밀과 미공개 증거는 노출하지 않는다.

## 진상 공개
- 기존 assets/reveal-narration.mp3 음성(README 기준 약 197.4초)을 기준으로 편집한다. 실제 길이는 확인한다.
- index.html의 진상 장면 데이터를 원본으로 삼고, 동기·수법·증거의 연결 순서를 유지한다.
- 기존 reveal 이미지와 증거 이미지를 사용해 음성에서 언급하는 대상을 강조한다.
- 마지막에 사건의 인과관계와 핵심 증거를 요약한다.
- 영상 후에는 웹에서 장면별 설명을 다시 읽을 수 있게 유지한다.

## 편집·연동 기준
- 공용 화면용 16:9, 본문 자막은 모바일 영상이 아닌 현장 화면의 시청 거리를 기준으로 확인한다.
- 배경음보다 음성을 우선하고, 자막은 영상에 포함한다.
- 재생·일시정지·처음부터·건너뛰기를 제공한다.
- 영상 종료 이벤트로 다음 화면을 연결한다. 영상 오류 시 기존 장면 재생을 제공한다.
- 최종 대본·음성·장면 길이를 확정한 뒤 렌더링하고, 웹 연동은 완성 MP4를 확보한 후 진행한다.
