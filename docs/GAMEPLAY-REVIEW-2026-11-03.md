# 기억 연출 적용 후 게임 진행 검토

2026-11-03. 기준: 이미 배포된 e143ed0 및 후속 로컬 수정. 기존 게임 방은 변경하지 않고 별도 서버 시험 방 W9LV를 사용했다.

## 재현하고 수정한 내용

1. 여섯 기억을 완료하기 전에는 수첩의 관계·행적·자기소개를 바로 열기 어려웠다. 새로고침 후 재입장한 사용자는 특히 진행 흐름에 뒤처질 수 있다. 첫 화면의 바로 보기, 상단 인물명, 하단 내 역할에서 미완독 상태로도 수첩을 열도록 수정했다. 읽기 완료 여부와 분리했으며 마지막 범인 여부의 확인 절차는 유지했다.
2. 배경 설명을 펼친 뒤 화면을 덮으면 돌아왔을 때 설명이 닫혔다. 덮기 전에 실제 펼침 상태와 스크롤을 저장하고, 반복된 덮기 이벤트가 저장 상태를 덮어쓰지 않도록 수정했다. 움직임 설정 변경에도 동일하게 적용했다.

## 확인 결과

- 한소설 실제 화면에서 미완독 수첩, 자기소개, 전체 배경 접근 확인. 이후 여섯 기억을 읽어도 마지막 정체는 여전히 잠겨 있으며 확인 후에만 완료 가능했다.
- 모바일 390×844에서 배경 전체를 펼쳐 스크롤 692px에서 덮기·이어서 보기 후 펼침 상태와 692px 위치가 동일했다.
- 진행자와 네 역할이 실제 Firebase 방 W9LV에 접속했다. 미완독 수첩의 현재 단계 버튼이 자기소개 예시 및 실제 조사 보드로 연결됐다.
- 한소설이 ‘남은 에피타이저 수프’를 확보했다. 별도 보관 클릭 없이 자동 보관됐고 조사 기회가 3회에서 2회로 줄었다.
- 카드 앞면이 열린 상태에서 새로고침했다. 진입 화면에서 같은 방에 다시 입장하자 단서 1장, 조사 기회 2회, 저택 잔여 9장이 복원됐다. 수첩에서 다시 기억을 완독하지 않고 조사로 이동할 수 있었다. 단서함에 같은 앞면 카드가 있었다.
- 다른 역할의 덮기 모달이 열려 있는 상태를 포함해 최종 투표로 전환됐다. 네 명 모두 제출했고 진행자에 4/4와 결과가 집계됐다.
- 투표한 한소설이 새로고침·재입장하자 선택과 제출 완료가 유지되고 변경은 막혔다. 진행자 새로고침 후에도 같은 방 W9LV, 최종 투표 단계와 4/4 집계가 복원됐다.
- 다음 단계에서 진상 공개 대기 화면이 표시됐다. 시험 종료 시 대기 상태로 두고 시험 탭을 닫았다.
- 진행자와 네 참가자 브라우저의 warn/error 로그는 비어 있었다.
- 네 Node 검사(캐릭터북, 게임, 조사 UI, 배포) 및 정적 사이트 빌드를 확인했다. 미완독 수첩 이동과 반복 덮기의 상태 보존에 회귀 검사를 추가했다.

## 범위와 한계

이 검토는 서버 연동 브라우저 시험이며 90분 전체의 실제 사용자 플레이테스트를 대신하지 않는다. 실제 iOS/Android의 앱 전환 미리보기, 여러 기기의 통신 단절 및 재연결은 현장 확인이 필요하다. 시나리오의 원본 사실, 단서 데이터, 조사 횟수 및 투표 규칙은 이번 수정에서 바꾸지 않았다.
