# 네 인물 캐릭터북 실제 적용

## 적용 위치
- 1.html 윤꽃집, 2.html 한소설, 3.html 백비서, 4.html 유감독.
- character-book-sample.html은 기존 한소설 독립 시안으로 유지.
- 기존 방 입장 화면을 통과하면 새 캐릭터북 표시. 실제 조사·단서함·투표는 기존 게임으로 연결.

## 공통 화면
10개 질문 순서: 인물 → 관계 → 비밀 확인 → 동기 → 배경 → 사건 전 행적 → 사건 무렵 → 기록 → 답변 원칙 → 자기소개.
얼굴 관계 카드, 3단계 동기, 장소별 행동 그림, 시간순 기록, 사물 카드, 질문별 참고, 읽던 위치 복원 제공.
비밀 확인은 눌러 공개하며, 최초 확인 전 다음 버튼 비활성화. 화면 이동·탭 비활성화·덮기 시 재가림.
역할 안내 중 하단 메뉴를 이전·다음 한 줄로 축소. 완료 후 조사·단서함 이동 및 빠른 참고 제공.

## 인물별 맥락
- 윤꽃집: 과거 배신과 해고 → 저택 근처 꽃집 → 파티에서 망신주려 한다는 말 → 한소설을 노린 행동 → 예상과 다른 착석 및 피해자. 실제 행적과 거짓 알리바이를 구분.
- 한소설: 아내의 과거 조사·계약상 배상 위험·투자 실패 → 유산/보험 조사 → 살충제 준비와 수프 투입. 백비서에게 확인시킨 대상은 테이블. 좌석 메모의 계획과 실제 착석 비교.
- 백비서: 남몰래 사랑함 → 이혼 목적의 협박편지 → 한소설을 노린 서재 물병. 16:00 얼음물 준비자와 19:31 주방 내부 행동은 모름을 명시. 홍대표가 마신 물을 준비했다고 오해하지 않게 구분.
- 유감독: 7:3 계약을 버틴 기대 → 해외 진출 의도 없음을 발견 → 한소설과의 협력/불신 → 홍대표 몫 과일청 준비. 통화는 17:40~18:05만 확인하며 사건 전체의 면죄부로 설명하지 않음.

## 원문과 규칙
원본 ME와 사건 단서·타임라인은 변경하지 않았다. rolebook-profiles.js는 각 인물 원문에 기반한 설명과 대응 예시를 제공한다.
범인 외 거짓말 불가 규칙과 충돌하던 ‘실행 안 했다’, ‘경고였을 뿐’, ‘사랑하지 않았다’ 등의 대응은 새 화면에서 사용하지 않는다.
비범인에게 실제 살인범의 정체나 목격하지 않은 주방 행동을 제공하지 않는다. 임의 좌석, 실제 지도, 추가 준비 시각을 생성하지 않는다.
기존 원문의 상세 배경은 ‘내 배경 전체’ 펼치기에서 확인 가능. 모든 원본 행적 시점과 기록 항목은 새 화면에 매핑.

## 기술 구성
- rolebook-ui.js: 공유 렌더러와 기존 게임 간 연결. Shadow DOM으로 기존 조사/단서함 CSS와 분리.
- rolebook-profiles.js: 인물별 맥락과 문장.
- rolebook-host.css + character-book-sample.css: 시안 디자인 공통 사용.
- 캐릭터북은 원본 ME를 직접 사용하며 서버/저장소를 별도로 생성하지 않음.
- 진행 중 투표가 시작되면 캐릭터북을 숨기고 기존 투표 화면에 제어를 넘김.

## 검증
- check-game.cjs / check-experience.cjs / check-rolebook.cjs 통과.
- 신규 검사: 네 인물 행적·기록 전체 매핑, 관계 초상, 인물별 정보 범위, 기존 조사 이동·투표 전환·입장 가림·배경 초점 분리.
- 실제 브라우저 오프라인: 네 인물 10페이지 완료, 비밀 공개, 조사·단서함 왕복, 비밀 재가림, 질문별 답변 확인.
- 390px 장면 확인 및 작은 화면 가로 넘침 점검. 오류 로그 없음.
- 실제 온라인 방에 참가하거나 서버 데이터를 변경하지 않았음. 초기 적용 당시에는 실제 4인 세션 동기화를 검증하지 않았으며, 후속 검증 결과는 SERVER-INTEGRATION-VERIFICATION.md 참고.
- 이미지: screenshots/rolebook-{yoon,han,baek,yoo}-live.png.

## 백비서·유감독 회의 참여 참고 보완
- 두 인물에 한해 ‘회의에서 무슨 말을 하지?’ 빠른 참고 추가. 역할 안내의 답변 원칙 화면에서도 선택적으로 펼칠 수 있음.
- 백비서: 16:00 식당 얼음물 잔, 19:31 주방에서 나오는 한소설. 준비자와 주방 안 행동을 모른다는 한계 병기.
- 유감독: 17:40~18:05 통화와 시사회 합류, 이미 알려진 홍대표와의 갈등. 통화 기록의 시간 범위를 한정.
- 비밀은 별도 펼치기 아래에 두고, 모두 먼저 공개하거나 특정 인물을 의심하도록 지시하지 않음.
- 원본 ME, 단서, 범행 설정, 동선, 공개 순서, 목표·점수, 시간표·투표 규칙은 변경하지 않음.
- 질문 예시는 기존 역할 정보만 사용. 백비서에게 편지가 다른 인물의 살해 결심을 촉발했다는 연결을 제공하지 않음. 유감독에게 한소설의 구체적인 실행 방법을 공유했다고 추가하지 않음.
