# 진행자 프롤로그·진상 영상 연결

사용자가 제공한 prologue-demo-v2.mp4와 reveal-demo-v3.mp4를 각각 assets/video/prologue-v2.mp4, reveal-v3.mp4로 연결했습니다. 영상·음성 스트림을 다시 인코딩하지 않고 MP4의 인덱스만 앞으로 옮겨 빠른 재생을 지원합니다. 원본과 결과의 압축 영상·음성 스트림 SHA-256이 일치합니다.

## 동작

- 시작 버튼: 프롤로그 재생. 자연 종료 또는 ‘다음 진행 · 오프닝 규칙’ 버튼으로 기존 규칙 단계 진입.
- 진상 공개 게이트: 첨부 진상 v3 영상 재생. 상영 종료 후 처음부터 다시 보기 제공.
- 기본 영상 조작부로 일시정지, 재생 위치 이동, 음량, 전체화면 사용. 별도 ‘10초 전’ 버튼 제공.
- 새로고침 시 현재 방의 저장 단계와 영상 위치를 복원하고 자동 음성 재생 없이 일시정지.
- 기존 나레이션·BGM·안내 읽기를 상영 중 중단하고, 영상 밖으로 나가면 기존 진행 화면과 음악 설정 복귀.
- 실패 시 연결 확인 안내와 다시 불러오기 버튼 제공.
- 프롤로그/진상 이외 게임 단계와 네 캐릭터 화면, 조사·투표 서버 로직은 유지.

## 확인 결과

- 기존 7개 자동 검사와 신규 check-host-cinema.cjs 검사 통과. 신규 검사는 영상 전환, 위치 저장·복원, 파일 버전 변경 시 초기화, 종료·재생, 이전 영상의 지연 이벤트 차단과 재시도를 검증.
- 공개 사이트 패키징 성공. 제작 과정의 docs/video-production 자료는 공개 사이트에 포함되지 않음.
- 브라우저: 서버 통신 스크립트만 제거한 동일 화면 복제본에서 확인. 실제 방 생성·참가자·투표 데이터 변경 없음.
- 프롤로그: 1920×1080, 131.708초 재생, 일시정지, 31.796초 위치에서 새로고침 후 같은 위치로 조용히 복원, 규칙 단계 이동 확인.
- 진상: 1920×1080, 250.760초 재생, 새로고침 후 26.021초 위치 복원, 상영 종료 및 처음부터 다시 재생 확인.
- 로컬 검증 서버는 영상 구간 다운로드(HTTP Range)를 지원하도록 구성. 일반 Python 정적 서버의 구간 이동 제한을 실제 앱 문제와 구분함.
- 브라우저 화면 증빙: screenshots/host-reveal-video-2026-11-17.png.

기존 이미지·대본 기반 상영 코드는 호환용으로 남아 있으며, 새 영상 모듈을 로드한 정상 배포에서는 실행하지 않습니다. 실기기 전체화면 전환과 느린 모바일 회선의 버퍼링은 별도 환경 검증 대상입니다.
