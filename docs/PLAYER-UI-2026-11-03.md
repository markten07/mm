# 플레이어 화면 UI 연결성과 펼침 안내 개선

## 반영

- 내 역할·조사·단서함에 같은 인물 초상/이름, 방 코드/현재 단계, 하단 아이콘 메뉴를 사용한다. 기존 상단 조사 탭과 별도 하단 단서 표시를 하나의 하단 메뉴로 정리했다. 단서 수는 단서함 배지에 나타난다.
- `player-design-system.css`에서 색·서체·버튼·여백·모서리·하단 메뉴를 공유한다. 기억 장면의 그림과 서사 제목은 유지하고 수첩과 게임 조작은 같은 시스템 글꼴과 색으로 맞췄다.
- 조사판의 강한 녹색 질감, 금색 외곽 테두리와 장식을 줄였다. 다섯 공간, 겹친 카드, 남은 장수, 카드 들기/뒤집기와 앞면 단서함은 유지한다.
- 접힌 설명에 질문 제목, 누를 이유를 알려주는 짧은 설명, 펼치기/접기와 화살표를 함께 표시한다. 기억 장면, 배경 설명, 질문별 참고에 같은 표현을 사용한다. 네이티브 details/summary와 버튼의 expanded 상태는 유지한다.
- 그림 높이를 내용 전체 대신 실제 읽기 영역 높이에 맞춘다. 펼친 글은 아래로 늘어나며 그림의 크기/크롭은 그대로다. 스크롤바 공간도 미리 확보해 펼칠 때 그림 폭이 줄어드는 현상을 막았다. 장면 그림 자체의 확대 애니메이션은 제거했다.
- 카드 보관 애니메이션은 새 단서함 메뉴를 향한다.

## 검증

- 네 인물의 390×844 화면에서 설명을 펼치기 전후 그림은 모두 379×542.953125px로 동일했다. 가로 넘침은 없고 하단 메뉴는 y=780~844에 유지됐다.
- 1280×800의 유감독 화면에서 그림은 펼치기 전후 609.84375×570px로 동일했다.
- 320×568에서 기억 화면의 진행 버튼과 하단 메뉴가 유지됐다. 가로 넘침 없이 설명은 읽기 영역에서 스크롤된다.
- 유감독의 1~5장면, 마지막 정체 잠금/공개와 수첩 완료를 확인했다. 배경 설명 펼침 후 덮기/복귀도 유지됐다.
- 새 Firebase 시험 방 DW5B에서 진행자와 네 인물을 연결했다. 새 하단 메뉴로 조사 진입, 한소설의 텀블러 확보/자동 보관, 단서함 배지 1, 같은 카드 확대를 확인했다.
- 윤꽃집이 펼친 기억을 덮은 상태, 한소설이 단서 카드를 확대한 상태에서 1차 투표가 모두 우선됐다. 내 역할 메뉴를 눌러도 투표를 우회하지 못했다. 네 명 제출 후 진행자가 4/4를 집계했다.
- 2차 조사로 넘어간 뒤 윤꽃집의 펼친 설명과 읽기 상태를 복원했다. 한소설은 새로고침/재입장 후 텀블러 및 단서함 배지 1을 복원했다. 단계 표시는 새 헤더에 반영됐다.
- 다섯 서버 시험 화면의 warn/error 로그는 비어 있었다. 시험 종료 시 진행자 타이머를 일시정지하고 시험 탭을 닫았다.
- 게임, 조사 UI, 역할북, 새 공통 메뉴, 배포 검사 5종 및 정적 빌드 통과. 공통 메뉴 검사는 네 인물, 단서 수 갱신, 서버 단계 변경, 투표 중 비활성 메뉴 상태와 원래 렌더 함수 실행을 확인한다.

브라우저 크기별 검증이다. 실제 휴대폰 OS의 앱 전환, 브라우저 글자 크기 설정과 장시간 플레이 사용성은 현장 확인 대상이다. 인물별 시나리오 사실, 단서, 조사 횟수 및 투표 규칙은 변경하지 않았다.
