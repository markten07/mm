# 화면 개선 작업 계획

작성일: 2026-10-26

## 진행 원칙
각 단계 시작 전에 채팅에서 간단한 흐름도 또는 화면 설명을 제공한 뒤 작업한다.
기존 시나리오, 인물별 비밀, 단서 배분과 라운드 제한을 유지한다.

## 순서와 완료 기준
1. 진행 규칙·안내 통일: 휴대폰 투표로 안내 통일, 제출 전 변경 불가 안내, 단계별 지금 할 일 안내.
2. 조사·단서함: 공간별 카드 더미, 공간 출처 표시, 카드 공개와 자동 보관, 남은 조사 기회, 장소별 보관 카드.
   휴대폰에서는 선택 화면을 간결하게 하고 긴 단서는 별도 상세에서 읽는다.
   전체 잔여 단서와 현재 획득 가능한 단서를 구분하되 인물별 제한 사유는 노출하지 않는다.
3. 비밀·투표: 비밀을 다시 덮기, 비밀 카드 구분, 인물 카드 선택 후 별도 제출, 제출 후 대기 안내.
4. 진행자: 중립적인 담당 형사 캐릭터, 단계별 대사와 다음 행동, 현재 단계·타이머 유지.
   실제 읽기 완료·조사 완료 집계는 별도 상태 설계가 필요하며 허위 수치를 표시하지 않는다.
5. 영상 구성: 프롤로그·진상 공개 영상용 구성안 저장. 기존 이미지·음성 재생은 유지.
   완성 영상 파일 제작은 영상 제작 환경과 최종 대본·연출 확정 후 진행.

## 조사 보드 개편 — 전체 반영
- 인물별 분류 탭을 제거하고 저택·한소설·백비서·유감독·윤꽃집의 다섯 받침판을 동시에 표시.
- 저택과 각 인물의 세부 장소를 하나의 카드 풀로 합침. 해당 풀의 확보 가능한 단서 중 무작위 한 장을 선택하며 카드 앞면에는 원래 발견 위치를 유지.
- 카드들은 옆으로 나열하지 않고 포갠다. 남은 카드마다 겹침 레이어를 만들고 장수에 따라 두께가 달라진다. 0장이면 빈 받침판을 유지.
- 카드 뒷면에는 공간별 색·건물 문양·이름을 표시. 앞면은 증거 이름·이미지·발견 위치·설명을 담은 종이 카드.
- 맨 위 카드 선택 → 선택 위치에서 들어 올리기 → 서버 확보 성공 후 뒤집기 → 직접 읽기 → 단서함에 넣기 → 카드가 하단으로 이동.
- 서버 저장은 확보 성공 시점에 완료. 보관 애니메이션 도중 새로고침해도 온라인 단서는 복원됨.
- 네트워크 응답 중 중복 선택 차단, 실시간 업데이트와 마지막 조사 횟수의 중복 차감 방지, 늦게 도착한 응답이 다음 라운드의 횟수나 화면을 덮지 않도록 처리.
- 모달의 긴 본문만 스크롤하며 키보드 Escape로 닫기 가능. 동작 줄이기 설정에서는 회전·이동 효과 생략.

## 자동 보관 안내·단서함 앞면 통일
- 단서는 서버 확보 성공 시 자동 보관된다. 읽기 화면을 닫거나 확인 버튼을 누르지 않아도 확보 기록과 조사 횟수는 유지된다.
- 기존 ‘단서함에 넣기’를 ‘보관 완료 · 조사 계속하기’로 변경하고 앞면·하단에 자동 보관 완료 안내를 표시.
- 조사 공개 화면과 단서함 목록·확대 화면이 같은 앞면 생성 함수를 사용하도록 통일. 목록에는 발견 위치·이미지·제목·본문 미리보기를 표시.
- 단서함은 앞면 상태로 들어 올려 확대하며 다시 뒤집지 않는다. 닫을 때 원래 카드 자리로 축소되고 목록 스크롤·초점을 복원한다.
- 중요 표시한 카드는 해당 공간 안에서 별표만 표시하여 중복 카드를 제거.
- 보관 카드 확대는 새 단서 선점·조사 횟수 차감을 발생시키지 않음. 미확보 카드는 확대 불가.
- 자동 검사 2종 통과. 실제 브라우저에서 확인 버튼 없이 Escape로 닫은 후 단서 보관, 앞면 목록, 확대·복귀·중요 표시 확인.
- 검증 이미지: screenshots/clue-kit-fronts.png, screenshots/clue-kit-expanded.png.
